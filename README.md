# UI Overhaul

A UI overhaul for Chivalry 2 (Unchained) that works on every map and mode.

## Features

- Exact health and stamina numbers on your own bars
- Spectator overhead bar on every player: health, stamina and weapon icon
- Spectator camera switch between first and third person

Other players' stamina is only shown to pure spectators, never to dead players on the death cam, so it can't be used to gain an edge.

## Install

Install through the Unchained launcher, or download `UIOverhaul.pak` from the latest release.
